# Awesome-Generative-AI-Copilot

## Top Generative AI Copilot Tools Ecosystem



**Curated List of SaaS Products & Open-Source GitHub Projects**  

*Focused on AI Assistants, Agentic Workflows & Context-Aware Productivity*  

**Last updated: March 2026**



This repository tracks notable **SaaS platforms** and **open-source projects** for **Generative AI Copilots**. These tools embed large language models directly into productivity, development, and business workflows — providing code completion, document drafting, meeting summarization, and autonomous task execution with context awareness and human-in-the-loop controls.



**Examples** include Salesforce Einstein Copilot, Microsoft 365 Copilot, GitHub Copilot, Google Workspace Gemini, Notion AI, ServiceNow Now Assist, HubSpot ChatSpot, Atlassian Intelligence, Freshworks Freddy Copilot, and Zoom AI Companion (the category leaders).



**Open-source emphasis**: This section is heavily expanded with every major active project for self-hosting, custom LLM integration, and transparent AI agent workflows — ideal for teams prioritizing data sovereignty, developers building AI-native applications, and organizations avoiding per-seat AI taxes.



Contributions welcome! Open a PR to add/update entries. Keep descriptions factual and link to official sites.

## SaaS/Hosted Platforms



- **[Salesforce Einstein Copilot](https://www.salesforce.com/)**  

  Generative AI assistant within Salesforce for natural language CRM queries, email drafting, and Agentforce autonomous task execution.



- **[Microsoft 365 Copilot](https://www.microsoft.com/en-us/microsoft-365)**  

  AI assistant across Word, Excel, PowerPoint, Outlook, and Teams with enterprise data grounding and Graph integration.



- **[GitHub Copilot](https://github.com/features/copilot)**  

  AI pair programmer with code completion, chat, and agent mode across VS Code, JetBrains, Visual Studio, and GitHub.com. Moving to usage-based AI Credits billing in June 2026 .



- **[Google Workspace Gemini](https://workspace.google.com/)**  

  AI assistant across Gmail, Docs, Sheets, and Meet with Google's Gemini models and enterprise data controls.



- **[Notion AI](https://www.notion.com/)**  

  AI writing assistant and Q&A within Notion workspace for drafting, summarizing, and knowledge retrieval.



- **[ServiceNow Now Assist](https://www.servicenow.com/)**  

  Generative AI across ServiceNow platform for ticket summarization, code generation, and workflow automation.



- **[HubSpot ChatSpot](https://www.hubspot.com/)**  

  Conversational CRM assistant powered by ChatGPT for natural language data queries and task execution.



- **[Atlassian Intelligence](https://www.atlassian.com/)**  

  AI across Jira, Confluence, and Bitbucket for content generation, summarization, and workflow assistance.



- **[Freshworks Freddy Copilot](https://www.freshworks.com/)**  

  AI assistant across Freshworks products for ticket summarization, response drafting, and agent assistance.



- **[Zoom AI Companion](https://www.zoom.com/)**  

  AI meeting assistant with transcription, summarization, and action item extraction integrated into Zoom workflows.



## Open-Source GitHub Projects



- **[NanoClaw](https://github.com/nanoco-ai/nanoclaw)**  

  Open-source AI agent framework with 29K+ GitHub stars and 250K+ downloads. Runs in Docker-powered sandboxes with credential injection at runtime — agents never hold secrets. Adapts to employee roles through conversation, retains context across projects, and supports human approval workflows. Enterprise product available with deployment into customer infrastructure . Featured in enterprise evaluations for teams wanting fully controlled AI assistants .



- **[Cline](https://github.com/cline/cline)**  

  Open-source autonomous coding agent for VS Code, JetBrains, and CLI with 62,996+ GitHub stars. Supports 46 providers including Anthropic, OpenAI, Google, and local models via Ollama. Human-in-the-loop by default with step-by-step approval. MCP integration most mature of any coding agent. Enterprise features include SSO, audit trails, and remote config .



- **[Aider](https://github.com/Aider-AI/aider)**  

  Terminal-based AI pair programming with 30K+ stars. Connects to git repository, builds internal codebase map, makes edits, and auto-commits with descriptive messages. Supports virtually every major model provider including Claude, GPT-4o, DeepSeek, and local models. Best-in-class git integration with automatic linting and test-running self-correction loops .



- **[OpenHands](https://github.com/OpenHands/OpenHands)**  

  Platform for building and running AI coding agents with 68K+ stars and $18.8M Series A funding. Sandboxed execution environments, multi-session management, and universal agent controller. Achieves 77.6% on SWE-Bench. MIT licensed core with enterprise directory .



- **[Goose](https://github.com/aaif-goose/goose)**  

  Rust-based general-purpose AI agent from Block, now under Agentic AI Foundation at Linux Foundation. 48,542+ stars. Desktop app for macOS, Linux, Windows plus CLI and API. Works with 15+ providers and connects to 70+ extensions over MCP. Positions for research, writing, automation, and data analysis alongside coding .



- **[TPT Anvil](https://github.com/tpt-solutions/tpt-anvil)**  

  Fully open-source, privacy-first alternative to GitHub Copilot and Cursor. Local LLM inference via llama.cpp, candle, or Ollama with any GGUF model. GPU acceleration (CUDA, ROCm, WebGPU). Codebase-aware context with Tree-sitter AST and hybrid semantic search. Cloud fallback (BYOK) with live model lists. VS Code extension and JetBrains plugin. 100% local by default, zero telemetry .



- **[Tabby](https://github.com/TabbyML/tabby)**  

  Self-hosted AI coding assistant and on-premises alternative to GitHub Copilot. Self-contained with no DBMS or cloud service required. OpenAPI interface for integration. Supports consumer-grade GPUs. Includes Answer Engine for internal knowledge and repo-context indexing .



- **[Continue.dev](https://github.com/continuedev/continue)**  

  Open-source AI code assistant for VS Code and JetBrains with 31K+ stars. Model-agnostic architecture supporting any LLM including local Ollama. Source-controlled AI checks enforceable in CI. Autocomplete, chat, edit, and agent capabilities. On-prem, cloud, or fully offline deployment .



- **[Wukong AICRM](https://github.com/WuKongOpenSource/Wukong-AICRM)**  

  Open-source AI CRM and Salesforce alternative powered by conversational AI. Features AI dialogue assistant, knowledge base RAG enhancement, intelligent customer management, AI task generation, and email integration (Gmail, Outlook, IMAP/SMTP). Java 21 / Spring Boot 3.x / Spring AI stack with PostgreSQL, Redis, MinIO .



- **[OpenCode](https://github.com/anomalyco/opencode)**  

  Terminal-native AI coding agent with 172,198 GitHub stars — most-starred open-source coding agent. MIT licensed, free with BYOK across 75+ providers via AI SDK and Models.dev catalog. Native remote/SSH support. OpenCode Zen for curated model recommendations .



- **[Kilo Code](https://github.com/Kilo-Org/kilocode)**  

  Open-source AI coding agent for VS Code, JetBrains, CLI, Cloud, and Slack with 19,968+ stars. 500+ supported models. Parallel agents. Free tier with optional Kilo Pass inference from $19/mo. Absorbed Roo and Cline capabilities .



- **[Twinny](https://github.com/twinnydotdev/twinny)**  

  Free, private AI extension for VS Code with 3,639+ stars. Supports multiple models, code completion, chat, and P2P inference. Locally or API-hosted — "like GitHub Copilot but 100% free" .



### Additional Strong Open-Source Options



- **[eXo Platform](https://github.com/exoplatform)** — Open-source sovereign digital workplace with multi-model AI (Mistral, OpenAI, Anthropic, Gemini, local models) integrated directly into collaboration. Context-aware assistants respect access rights. RAG-based retrieval grounds AI in organization knowledge. On-premise available .

- **[Thunderbolt](https://github.com/thunderbird/thunderbolt)** — Mozilla's open-source, self-hosted enterprise AI client. Connects to MCP servers, ACP agents, and deepset's Haystack platform. Runs on single machine for sensitive data. Positioned as sovereign alternative to Copilot, ChatGPT Enterprise, and Claude Enterprise .

- **[ONLYOFFICE](https://github.com/ONLYOFFICE)** — Open-source office suite with contextual AI integrated into documents, spreadsheets, presentations, and PDFs. Supports OpenRouter, self-hosted models, and local execution. AI Agents app for research and knowledge base automation .

- **[GenOffice](https://github.com/genspark-ai/genoffice)** — Open-source AI-first office suite with Docs, Sheets, Slides, and PDF editors. Built-in AI agent for drafting, restyling, and data cards. `genoffice` CLI for Claude Code, Codex, and Cursor to create/edit real .docx/.xlsx/.pptx files .

- **[Mewbo Assistant](https://github.com/bearlike/Assistant)** — Open agentic stack with agent hypervisor, graph-powered repo wiki, Q&A, and search across connected tools. Any model, open source. Sandboxed execution with Landlock. Identity and access with OIDC/LDAP/SAML .



**Frameworks for building custom systems**: Combine **NanoClaw** for container-isolated AI agents, **Cline** or **Aider** for coding assistance, **TPT Anvil** for privacy-first local inference, **Wukong AICRM** for AI-native CRM workflows, and **Thunderbolt** for sovereign enterprise AI to build a complete self-hosted generative AI copilot stack.
